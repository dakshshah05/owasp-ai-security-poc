🔌 MCP Connection Risk POC

Model Context Protocol (MCP) security risks — malicious tools, injection via tool responses, and excessive permissions.

What is MCP?

Model Context Protocol (MCP) is an open protocol that allows AI models to connect to external tools and data sources via a standardized interface.

MCP Security Risks

  • MCP-01: Malicious MCP server exposes a tool that exfiltrates all data
  • MCP-02: Tool response contains injected instructions that hijack the AI
  • MCP-03: Server exposes admin tools without proper authorization checks
